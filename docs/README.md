# 문서 색인

이 폴더는 개발 중 항상 참조하는 제품·설계 기준을 보관한다. 구현을 시작하기 전에 이 문서와 관련 문서를 읽는다.

| 문서 | 목적 | 변경 시점 |
| --- | --- | --- |
| [MVP 요구사항](mvp-requirements.md) | 현재 제품 범위, 핵심 흐름, 수용 기준 | 사용자 요구 또는 MVP 범위 변경 시 |
| [로컬 개발 환경](implementation/local-development.md) | 로컬 DB·환경 변수·서버 이관 원칙 | 개발 환경을 준비하거나 배포할 때 |
| [백로그](backlog.md) | 현재 MVP에서 제외하거나 보류한 기능 | 새 아이디어가 범위 밖일 때 |
| `decisions/` | 승인된 제품·기술 결정 기록 | 설계 선택이 장기 영향이 있을 때 |
| `implementation/` | API, 스키마, 운영 등 구현 계약 | 구현 계약을 정할 때 |

## 문서 읽는 순서

1. `AGENTS.md`
2. 이 색인
3. `mvp-requirements.md`
4. 바꾸려는 영역과 관련된 `decisions/`, `implementation/` 문서

## 상태 표기

- **확정**: 구현과 테스트가 따라야 하는 합의 사항
- **보류**: 방향은 있으나 세부 선택이 남아 있는 사항
- **제외**: 현재 MVP에서는 만들지 않는 사항

새 문서는 사실·결정·가정을 분리하고, 각 결정에는 이유와 영향 범위를 남긴다.
