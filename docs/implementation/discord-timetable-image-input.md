# Discord 시간표 이미지 입력 계약

## 입력

- `DISCORD_INPUT_CHANNEL_ID`로 지정한 채널에서 사람 메시지만 처리한다.
- 메시지에 첨부 파일이 있으면 첨부 파일을 시간표 이미지로 처리한다.
- 한 번에 이미지 한 장만 허용한다. 여러 파일은 각각 나눠 보내도록 안내한다.
- 허용 형식은 JPEG, PNG, WebP이며 최대 크기는 10 MiB다. MIME 형식이 없을 때는 파일 확장자를 보조로 사용한다.
- 이미지 다운로드에는 10초 timeout을 적용한다. 이미지 URL과 바이트는 로그나 로컬 DB에 저장하지 않는다.
- 텍스트 캡션이 있으면 이미지 해석의 보조 맥락으로 전달한다.

## 출력과 데이터 변경

- 시간대는 현재 `Asia/Seoul`을 사용한다.
- AI 결과는 `ProposedTimetable` 스키마 검증 후 요일·과목·시간·강의실 미리보기로 반환한다.
- 읽기 어려운 값과 잘못된 시각 범위는 확인 필요 항목으로 표시한다.
- 이 구현 단계에서는 미리보기만 제공하며 Course/Schedule 데이터는 생성·수정하지 않는다.

## 실패 처리

- 지원하지 않는 파일 형식, 여러 첨부 파일, 10 MiB 초과 파일은 이유와 재시도 방법을 안내한다.
- 다운로드 또는 AI 해석 실패 시 저장 없이 다시 선명한 지원 형식 이미지를 요청한다.
- 응답은 Discord 메시지 길이 제한보다 짧은 조각으로 나눠 전송한다.
