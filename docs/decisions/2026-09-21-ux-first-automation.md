# 사용성 우선 및 자동화 중심 제품 원칙

## 상태

승인됨

## 결정

Discord AI 비서의 1순위 품질 기준은 모델의 답변 표현력이 아니라 사용자가 입력을 보낸 뒤 자동 처리가 끝까지 이어지는 경험이다.

- 사용자는 자연어 또는 이미지 하나를 보내는 것으로 시작한다.
- 이미지에서 필요한 정보를 자동 추출하고, 저장 전 검증과 확인이 필요한 경우에만 질문한다.
- 확정된 일정은 DB에 저장하고 예약 작업으로 연결한다.
- 예약 작업은 프로세스 재시작에도 복구되며, 중복 없이 알림을 발송한다.
- 각 단계의 성공·대기·실패 상태와 다음 행동을 Discord로 안내한다.

## 경계

AI는 이미지·텍스트를 구조화하고 의도를 분류하는 역할만 한다. 일정 저장, 예약 등록, 발송, 재시도, 중복 방지는 검증된 애플리케이션 코드와 저장소가 담당한다.

일정의 사실 원천은 PostgreSQL이다. Notion 같은 외부 서비스는 별도 기능으로 연결하더라도 일정 사실을 직접 덮어쓰지 않는다.

## 영향

- 이미지 처리 파이프라인은 비동기 작업과 진행 상태를 고려해야 한다.
- 알림 예약과 발송 이력은 MVP 핵심 범위로 취급한다.
- 외부 API 장애 시 사용자에게 명시적인 오류와 재시도 결과를 제공해야 한다.
- 기능을 추가할 때도 사용자가 Discord에서 한 번의 입력으로 시작할 수 있는지 먼저 검토한다.
