# 일반 대화 응답 경로

- 상태: 승인
- 날짜: 2026-10-07

## 맥락

Discord 입력 채널은 일정 요청 외에도 "뭐해?", "잘 듣고 있어?" 같은 자연스러운 대화에 사용된다. 기존에는 일정 intent 분류 결과 `UNKNOWN`과 빈 데이터를 그대로 보여줘 대화가 끊겼다.

## 결정

- `UNKNOWN` 입력은 AI 공급자 어댑터의 일반 대화 응답 기능으로 전달한다.
- 일반 대화 응답에는 현재 메시지와 시간대·수신 시각만 제공한다. 대화 이력이나 일정 DB 데이터를 불러오지 않는다.
- 일반 대화 입력과 답변은 애플리케이션 DB, 로그 또는 별도 메모리에 저장하지 않는다.
- 일정 intent가 분류된 경우 기존 일정 처리 경로를 유지한다. 일반 대화 응답은 일정 생성·변경을 수행하거나 수행했다고 주장하지 않는다.

## 이유와 영향

- 사용자는 별도 명령어 없이 비서에게 일상적으로 말을 걸 수 있다.
- 일반 대화는 요청 단위로 처리되므로 장기 대화 기억이나 추가 저장 모델을 도입하지 않는다.
- AI 어댑터 계약에는 일정 해석 및 이미지 해석과 구분되는 `respondToGeneralMessage` 기능이 포함된다.
