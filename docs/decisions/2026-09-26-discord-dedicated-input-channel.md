# Discord 전용 입력 채널

## 상태

승인됨

## 맥락

봇을 호출할 때마다 `@두부`를 멘션해야 하는 입력 방식이 번거롭다. 이 비서는 개인 일정 정보를 다루므로 서버의 모든 대화를 읽는 대신 전용 입력 지점을 사용한다.

## 결정

- `DISCORD_INPUT_CHANNEL_ID`에 지정된 서버 텍스트 채널을 유일한 입력 채널로 사용한다.
- 사용자는 그 채널에 자연어 또는 이미지를 바로 보낼 수 있고, 봇 멘션은 필요하지 않다.
- 봇은 해당 채널의 사람 메시지만 처리한다. 다른 채널, DM, 봇 메시지는 무시한다.
- 전용 채널은 사용자와 봇만 볼 수 있도록 Discord 권한을 설정한다.
- 서버 메시지의 본문과 첨부를 읽기 위해 Discord `Message Content Intent`를 활성화한다.

## 이유와 대안

전용 채널은 일반 대화와 비서 입력을 분리하면서도 자연어를 그대로 쓸 수 있다. DM은 채널 이동이 줄어드는 장점이 있지만, 이번 MVP에서는 서버 안의 입력 채널을 선택했다. 슬래시 명령은 매번 명령어를 시작해야 하므로 선택하지 않았다.

## 영향

- 런타임 환경 변수 `DISCORD_INPUT_CHANNEL_ID`가 필요하다.
- Discord 메시지 처리기는 설정된 채널 ID를 기준으로 입력을 거른다.
- 전용 채널 접근 권한에 따라 봇을 사용할 수 있는 사람이 결정된다.
- 일정 데이터 모델과 자동 알림 정책은 바뀌지 않는다.
