# MVP 이후 백로그

아래 항목은 아이디어를 보존하기 위한 목록이며, 현재 MVP의 구현 범위는 아니다.

| 항목 | 이유 | 재검토 조건 |
| --- | --- | --- |
| Notion 수업 노트 연동 | 일정 관리 핵심 흐름 검증 후 확장 | 수업·시험 알림이 안정적으로 운영될 때 |
| 시험 범위 요약·예상 문제·복습 계획 | 콘텐츠 생성 기능은 일정 데이터 기반이 갖춰진 뒤 도입 | Notion 등 신뢰할 수 있는 노트 원천이 연결될 때 |
| 웹/모바일 관리 UI | Discord 자연어 UX의 한계를 확인한 뒤 판단 | 사용자 설정·정정 요청이 반복적으로 불편할 때 |
| 공유 시간표와 다중 사용자 | 개인정보와 권한 모델이 필요 | 개인 사용자 흐름이 검증된 뒤 |
| 학사 시스템 자동 동기화 | 학교별 연동 복잡도가 큼 | 수동 등록 흐름이 충분히 검증된 뒤 |
